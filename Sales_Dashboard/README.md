Sales Dashboard — Power BI
Project Overview
This Power BI dashboard provides an interactive view of sales performance, order activity, profitability, returns, and shipping-related metrics. It is designed to help users explore business performance across product categories, markets, regions, countries, customers, and time periods.
Key Analysis Areas
Sales performance: Total sales and order volume.
Profitability: Total profit and performance across relevant business dimensions.
Returns: Total returns and return percentage.
Product analysis: Compare performance by product category and product name.
Geographic analysis: Explore sales and orders by country, region, and market.
Time-based analysis: Review trends by year and month.
Customer and delivery analysis: Explore customer-level patterns and shipping days.
Tools Used
Microsoft Power BI
Power Query and the data model used in the report
DAX measures for summary metrics
How to Use
Download `Sales_Dashboard_Krishna_Agrawal_Sec_B.pbix` from this repository.
Open the file in Microsoft Power BI Desktop.
Use the report's filters and visuals to explore different periods, products, regions, and markets.
