# Sales Dashboard — Power BI

## 1. Project Overview

This interactive Power BI dashboard provides insights into sales performance, profitability, order activity, product performance, returns, and shipping operations. It helps users explore business performance across different markets, regions, countries, products, and time periods.

## 2. Key Analysis Areas

- **Sales Performance:** Analyze total sales and order volume.
- **Profitability:** Evaluate total profit across relevant business dimensions.
- **Returns Analysis:** Examine product returns and return percentage.
- **Product Analysis:** Compare sales and profitability by product category and product name.
- **Geographic Analysis:** Explore sales across countries, regions, and markets.
- **Time-Based Analysis:** Identify trends across years and months.
- **Customer and Shipping Analysis:** Explore customer-level patterns and shipping days.

## 3. Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX measures
- Data modeling and interactive visualizations

## 4. How to Use the Dashboard

1. Download the Power BI file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the available visuals and filters to explore sales, products, regions, and markets.
