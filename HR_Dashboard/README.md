# HR Dashboard — Power BI

## 1. Project Overview

This interactive Power BI dashboard analyzes employee attrition and workforce indicators. It helps explore employee turnover, job satisfaction, work-life balance, and workforce patterns across different departments, job roles, and demographic groups.

## 2. Key Analysis Areas

- **Workforce Overview:** Examine total employee count and workforce distribution.
- **Employee Attrition:** Analyze the number of employees who left the organization and the attrition rate.
- **Department Analysis:** Compare attrition patterns across departments.
- **Job Role Analysis:** Explore workforce and attrition trends across job roles.
- **Demographic Analysis:** Examine available employee data by gender and other demographic categories.
- **Employee Satisfaction:** Review job satisfaction and work-life balance indicators.
- **Reasons for Leaving:** Explore recorded reasons associated with employee departures.

## 3. Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX measures
- Data modeling and interactive visualizations

## 4. How to Use the Dashboard

1. Download the Power BI file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report visuals and available filters to analyze employee and attrition patterns.
