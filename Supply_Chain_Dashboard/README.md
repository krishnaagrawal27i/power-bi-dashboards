# Supply Chain Performance Dashboard — Power BI

## 1. Project Overview

This interactive Power BI dashboard examines supply chain operations, logistics costs, supplier performance, product quantities, lead times, and quality indicators. It supports the analysis of operational efficiency and potential areas for improvement.

## 2. Key Analysis Areas

- **Product Overview:** Examine total SKUs and quantities.
- **Cost Analysis:** Review total cost and shipping cost.
- **Supplier Analysis:** Compare supply chain indicators across suppliers.
- **Quality Analysis:** Explore defect rates and inspection outcomes.
- **Logistics Analysis:** Examine transportation modes, routes, and locations.
- **Lead Time Analysis:** Investigate lead-time patterns across relevant categories.
- **Product Analysis:** Compare operational indicators across product types.
- **Customer Profile Analysis:** Explore available customer demographic dimensions.

## 3. Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX measures
- Data modeling and interactive visualizations

## 4. How to Use the Dashboard

1. Download the Power BI file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the available visuals and filters to explore supplier, product, cost, logistics, and quality indicators.
